start the recorder first

The backend isn't running. Start it on this machine and the page will find it by itself.

1
install the daemon

Python 3.11 or newer.

git clone https://github.com/Ivoryy06/BlackboxD.git
cd BlackboxD
pip install -e .
2
start recording

Hyprland and GNOME are auto-detected; --backend mock is nice for a test run.

blackboxd --backend hyprland
3
open a dashboard

Either serve it straight from SQLite, or run the Go API on port 8080.

blackboxd-report serve
# or
cd go-api && go build -o blackboxd-api . && ./blackboxd-api
nothing leaves this machine ✿
