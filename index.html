Start BlackboxD first
The backend isn't running. Start it on your own machine and this page will find it by itself.
this page only talks to localhost:8080. nothing gets uploaded.
1. install
git clone https://github.com/Ivoryy06/BlackboxD.git cd BlackboxD && chmod +x install.sh && ./install.sh
2. start the daemon
blackboxd start
3. start the API
cd go-api && ./blackboxd-api
